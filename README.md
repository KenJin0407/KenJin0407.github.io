## 💻 Local Development Setup

Kung nais i-run ang portfolio sa iyong computer:

1. **I-clone ang repository:**
   ```bash
   git clone https://github.com/KenJin0407/github-portfolio.git
   cd github-portfolio/prince-angel
   ```

2. **Patakbuhin ang local preview server:**
   ```bash
   npm run dev
   ```

3. Buksan ang lalabas na local URL (karaniwan ay `http://localhost:8081`) sa iyong browser.
